**Installer un jeu** : brancher la calculatrice en USB, choisir **USB Flash**
(touche F1), copier le fichier `.g1a` à la racine du disque, puis éjecter.
Le jeu apparaît dans le menu principal. Tous les détails sont dans le README
de chaque jeu.

Les jeux sont en français, sous licence MIT, et testés automatiquement à
chaque modification.
